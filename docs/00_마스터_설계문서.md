## 1. 프로젝트 개요

### 1.1 비전
서울오토갤러리 및 대한민국 자동차 매매시장의 오프라인 자산을 디지털화하여 글로벌 바이어와 국내 자산가를 직접 연결하는 하이퍼카 거래 플랫폼

### 1.2 핵심 가치
- **신뢰**: 검증된 차량 정보와 전문가 검수 리포트
- **글로벌**: 다국어/다통화 지원, 해외 바이어 접근
- **프리미엄**: 럭셔리 브랜드에 걸맞는 시각적 경험
- **효율**: 불필요한 대면 협상 감소, 거래 속도 향상

## 8. 보안 요구사항

### 8.1 인증/인가
- JWT 기반 인증 (Access Token + Refresh Token)
- 역할 기반 접근 제어 (RBAC): buyer, seller, admin
- HttpOnly Cookie로 토큰 저장

### 8.2 데이터 보안
- 비밀번호: bcrypt (salt rounds: 12)
- VIN: AES-256 암호화
- 민감 정보: 마스킹 처리

### 8.3 API 보안
- HTTPS 강제 (TLS 1.3)
- CORS 제한 (도메인 화이트리스트)
- Rate Limiting: 100 req/min per IP
- SQL Injection 방지: Prisma 파라미터화 쿼리
- XSS 방지: 입력 값 sanitize
