# Hyper-Connect MVP 페이지 구조 설계서

**프로젝트명**: Hyper-Connect (MVP)
**작성일**: 2026-01-18
**버전**: 1.0
**Framework**: Next.js 14 (App Router)

---

## 1. 개요

### 1.1 목적
F1. 하이엔드 자산 등록 기능을 중심으로 Frontend 페이지 및 컴포넌트 구조를 설계합니다.

### 1.2 설계 원칙
1. **Next.js 14 App Router**: 최신 라우팅 시스템 활용
2. **컴포넌트 재사용**: Atomic Design 패턴
3. **타입 안전성**: TypeScript strict mode
4. **접근성**: WCAG 2.1 AA 준수

## 4. 주요 페이지 상세 설계

### 4.1 홈 페이지 (`/`)

**파일**: `app/(main)/page.tsx`

**렌더링 방식**: SSG (Static Generation) + ISR (5분)

**컴포넌트 구조**:
```tsx
export default async function HomePage() {
  const featuredVehicle = await getFeaturedVehicle();
  const verifiedInventory = await getVerifiedInventory();

  return (
    <>
      <HeroSection vehicle={featuredVehicle} />
      <QuickMenu />
      <VerifiedInventorySection vehicles={verifiedInventory} />
      <MarketInsightSection />
    </>
  );
}
```

**주요 컴포넌트**:
- `HeroSection`: 4K 영상 배경, 이달의 하이퍼카

### 4.4 차량 등록 (`/vehicles/new`) - F1 핵심

**파일**: `app/(main)/vehicles/new/page.tsx`

**렌더링 방식**: CSR (Client-Side Rendering)

**상태 관리**: React Hook Form + Zustand

**컴포넌트 구조**:
```tsx
'use client';

export default function VehicleRegistrationPage() {
  const [currentStep, setCurrentStep] = useState(1);
  const form = useForm<VehicleFormData>();

  return (
    <div className="container mx-auto max-w-4xl">
      <ProgressBar currentStep={currentStep} totalSteps={6} />

      <form onSubmit={form.handleSubmit(onSubmit)}>
        {currentStep === 1 && <Step1BasicInfo form={form} />}
        {currentStep === 2 && <Step2Options form={form} />}
        {currentStep === 3 && <Step3Maintenance form={form} />}
        {currentStep === 4 && <Step4Consumables form={form} />}
        {currentStep === 5 && <Step5Media form={form} />}
        {currentStep === 6 && <Step6Review form={form} />}

        <div className="flex justify-between mt-8">
          <Button
            variant="outline"
            onClick={() => setCurrentStep(prev => prev - 1)}
            disabled={currentStep === 1}
          >
            이전
          </Button>

          {currentStep < 6 ? (
            <Button onClick={() => setCurrentStep(prev => prev + 1)}>
              다음
            </Button>
          ) : (
            <Button type="submit">제출</Button>
          )}
        </div>
      </form>
    </div>
  );
}
```

**Step별 컴포넌트**:

#### Step 1: 기본 정보
- 제조사 (Select)
- 모델명 (Input)
- 연식 (Year Picker)
- 주행거리 (Number Input)
- VIN (Input with validation)
- 매칭넘버 여부 (Radio)
- 희망 판매가 (Number Input with comma formatting)

#### Step 2: 옵션 선택
- 브랜드별 옵션 체크박스 (카테고리별 그룹화)
- 최소 3개 선택 강제
- 기타 옵션 텍스트 입력

#### Step 3: 정비 이력
- 정비 이력 추가 버튼
- 각 이력당:
  - 정비 일자 (Date Picker)
  - 정비소 이름 (Input)
  - 정비 내용 (Textarea)
  - 문서 업로드 (PDF/Image)

#### Step 4: 소모품 상태
- 타이어: 잔량 슬라이더, 교체 일자, 브랜드
- 브레이크: 패드 두께, 디스크 상태 선택
- 엔진오일: 교체 일자, 교체 후 주행거리

#### Step 5: 미디어 업로드
- 드래그 앤 드롭 영역
- 최소 20장 강제
- 이미지 미리보기 그리드
- 순서 변경 (드래그 앤 드롭)
- 진행률 표시

#### Step 6: 최종 확인
- 입력한 모든 정보 요약
- 수정 버튼 (각 Step으로 이동)
- 제출 버튼

## 6. 상태 관리 전략

### 6.1 Server State (TanStack Query)

**차량 데이터**:
```tsx
// hooks/useVehicles.ts
export function useVehicles(filters: VehicleFilters) {
  return useQuery({
    queryKey: ['vehicles', filters],
    queryFn: () => apiClient.getVehicles(filters),
    staleTime: 5 * 60 * 1000, // 5분
  });
}
```

**Mutation 예시**:
```tsx
// hooks/useCreateVehicle.ts
export function useCreateVehicle() {
  const queryClient = useQueryClient();

  return useMutation({
    mutationFn: apiClient.createVehicle,
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['vehicles'] });
    },
  });
}
```
