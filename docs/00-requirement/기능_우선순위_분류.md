# Hyper-Connect MVP 기능 우선순위 분류

**프로젝트명**: Hyper-Connect (MVP)
**작성일**: 2026-01-18
**버전**: 1.0
**최우선 개발**: F1. 하이엔드 자산 등록

---

## 우선순위 정의

| 등급 | 정의 | 개발 시점 |
|------|------|----------|
| **P0 (필수)** | MVP 출시를 위해 반드시 구현해야 하는 핵심 기능 | Phase 1 (즉시) |
| **P1 (중요)** | 사용자 경험을 크게 향상시키지만 단계적 구현 가능 | Phase 2 (1개월 후) |
| **P2 (개선)** | 있으면 좋지만 없어도 서비스 운영 가능 | Phase 3 (2개월 후) |

## P0 (필수) - MVP 핵심 기능

### 1. F1. 하이엔드 자산 등록 시스템 ⭐ **[최우선]**

**구현 범위**:

#### 1.1 기본 정보 입력 폼
- [ ] 제조사 선택 (드롭다운)
- [ ] 모델명 입력 (텍스트)
- [ ] 연식 선택 (년도 선택기)
- [ ] 주행거리 입력 (숫자, 단위: km)
- [ ] VIN(차대번호) 입력 (영숫자 17자리 검증)
- [ ] 차량등록번호 입력 (선택 사항)
- [ ] 매칭넘버 여부 (Yes/No 라디오 버튼)

**우선순위**: P0
**예상 작업량**: 3일

---

#### 1.2 옵션표 강제 입력
- [ ] 브랜드별 주요 옵션 DB 구축
  - 페라리: 카본 브레이크, 리프트, 레이싱 시트 등
  - 포르쉐: PCCB, 스포츠 크로노, PDLS 등
  - 람보르기니: 에어로 패키지, 카본 외장, 브란딩 캘리퍼 등
- [ ] 체크박스 또는 멀티 셀렉트 UI
- [ ] 최소 3개 이상 선택 강제 (비즈니스 규칙)
- [ ] 기타 옵션 텍스트 입력 필드 (선택 사항)

**우선순위**: P0
**예상 작업량**: 5일

---

#### 1.3 정비 이력 업로드 (이미지/PDF)
- [ ] 파일 업로드 컴포넌트
  - 지원 포맷: JPG, PNG, PDF
  - 최대 파일 크기: 10MB/파일
  - 총 업로드 용량: 50MB
- [ ] 정비 내역 메타데이터 입력
  - 정비 날짜 (Date Picker)
  - 정비소 이름 (텍스트)
  - 정비 항목 (예: 엔진오일 교체, 브레이크 패드 교체)
- [ ] 파일 미리보기 및 삭제 기능
- [ ] S3 또는 Cloud Storage 연동

**우선순위**: P0
**예상 작업량**: 4일

---

#### 1.4 소모품 상태 입력
- [ ] **타이어**
  - 잔량(%): 슬라이더 또는 숫자 입력
  - 교체 일자: Date Picker
  - 브랜드/모델: 텍스트 입력
- [ ] **브레이크**
  - 패드 두께(mm): 숫자 입력
  - 디스크 상태: 드롭다운 (양호/교체 필요/교체 완료)
- [ ] **엔진오일**
  - 교체 일자: Date Picker
  - 교체 후 주행거리: 숫자 입력 (km)

**우선순위**: P0
**예상 작업량**: 3일

---

#### 1.5 미디어 자료 업로드
- [ ] **외관/내부 사진**
  - 최소 20장 강제 (비즈니스 규칙)
  - 이미지 압축 및 리사이징 (자동)
  - 드래그 앤 드롭 지원
- [ ] **4K 영상** (선택 사항)
  - 전문 촬영 예약 버튼 연동
  - 또는 직접 업로드 (최대 500MB)
- [ ] **엔진 사운드 클립** (선택 사항)
  - 오디오 파일 업로드 (MP3, WAV, 최대 20MB)
  - 재생 미리보기 기능

**우선순위**:
- 사진 업로드: P0
- 4K 영상: P1
- 엔진 사운드: P2

**예상 작업량**: 5일 (P0만)

---

#### 1.6 등록 검증 및 제출
- [ ] 필수 항목 미입력 시 경고 메시지
- [ ] 진행률 표시 바 (예: 70% 완료)
- [ ] 임시 저장 기능 (Draft)
- [ ] 최종 제출 시 관리자 승인 대기 상태로 전환
- [ ] 제출 완료 후 알림 및 대시보드로 이동

**우선순위**: P0
**예상 작업량**: 2일

---

- [ ] 등록된 차량 목록 표시 (카드 형태)

## 위험 요소 및 대응

| 위험 요소 | 영향도 | 대응 방안 |
|----------|--------|----------|
| 미디어 파일 처리 복잡도 | 높음 | CDN 조기 도입, 이미지 압축 자동화 |
| 브랜드별 옵션 DB 구축 | 중간 | 주요 브랜드 3개만 우선 구축 |
| 관리자 승인 병목 | 중간 | 자동 승인 조건 추가 (예: 신뢰 판매자) |
| 모바일 UX 최적화 | 높음 | 반응형 디자인 초기 설계 단계부터 적용 |
