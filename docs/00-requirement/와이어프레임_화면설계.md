# Hyper-Connect 와이어프레임 (화면 설계도)

**프로젝트명**: Hyper-Connect (MVP)
**작성일**: 2026-01-18
**버전**: 1.0

---

## 개요

개발팀이 앱의 핵심 로직과 UI 흐름을 즉시 이해할 수 있도록, **Hyper-Connect**의 핵심 화면 4종에 대한 와이어프레임 설계도입니다.

슈퍼카/하이퍼카 앱은 일반 중고차 앱과 달리 **'정보의 밀도'**와 **'럭셔리한 시각적 경험'**이 동시에 충족되어야 합니다.

---

## 화면 1: 메인 홈 (Global Curation)

2. **Quick Menu**: 핵심 액션으로의 빠른 접근
3. **Verified Inventory**: 신뢰도 배지(Grade)로 차별화
4. **Market Insight**: 글로벌 시장 정보로 신뢰성 강화

## 개발팀을 위한 기술 요구사항 요약

### 1. 다국어/다통화 처리
- **기술**: i18n 라이브러리 (react-i18next, vue-i18n)
- **환율 API**: 실시간 환율 연동 (ExchangeRate-API, Fixer.io)
- **RTL 레이아웃**: 아랍어 지원 시 CSS 대응

### 2. 고용량 미디어 서버
- **CDN**: AWS CloudFront, Cloudflare
- **이미지 최적화**: Sharp, ImageMagick (자동 리사이징/압축)
- **4K 영상**: Adaptive Bitrate Streaming (HLS, DASH)

### 3. 푸시 알림 엔진
- **기술**: Firebase Cloud Messaging (FCM)
- **요구사항**: 오퍼 발생 시 0.1초 내 알림
- **플로우**: 오퍼 등록 → FCM 서버 → 판매자 디바이스

### 4. 보안/인증
- **2FA**: TOTP (Time-based OTP) 또는 SMS 인증
- **데이터 암호화**: AWS KMS, AES-256
- **민감 정보 마스킹**: 차량등록증, 신분증 자동 블러 처리
